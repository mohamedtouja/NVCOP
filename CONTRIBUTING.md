# Contributing to NovaGraph

Thank you for considering contributing!

- Follow Git Flow with branches described in ROADMAP.md.
- Use Conventional Commits for commit messages.
- Run `cargo fmt` and `cargo clippy` for Rust changes.
- Run `black`, `ruff`, and `pytest` for Python changes.
- Open PRs against `develop` for features and fixes; `main` only receives release merges.
