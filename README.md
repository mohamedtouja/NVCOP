# NovaGraph

NovaGraph is a modular, research-driven lossless compression platform.

This repository contains two related projects:

- `python/` — NovaGraph-Lab (research, prototypes, ML experiments)
- `rust/` — NovaGraph-Engine (production-grade, high-performance)
