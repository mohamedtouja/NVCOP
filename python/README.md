# NovaGraph-Lab (Python)

This is the research workspace. The actual Lab repository is available at
`NovaGraph-Lab/` in this workspace (see top-level `NovaGraph-Lab/README.md`).

Quick start (recommended):

```bash
cd NovaGraph-Lab
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```
